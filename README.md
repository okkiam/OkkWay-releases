# OkkWay

Утилита для Windows x64, которая помогает подключиться к Discord. Окно объединяет три профиля подключения и пять проверок доступности. Для установки и обновлений аккаунт GitHub не нужен.

**[Скачать OkkWay для Windows x64](https://github.com/okkiam/OkkWay-releases/releases/latest/download/OkkWay-Setup.exe)** · [Все версии и изменения](https://github.com/okkiam/OkkWay-releases/releases)

## Первый запуск

1. Запустите **OkkWay-Setup.exe**. Для работы нужен .NET 10 Desktop Runtime x64. Установщик проверит его наличие.
2. Откройте OkkWay через меню «Пуск». Для проверки прямого подключения отключите VPN. Закройте другую запущенную копию zapret, если она у вас есть.
3. В разделе Discord выбран профиль **C**. Нажмите **«Включить обход»** и подтвердите запрос Windows на запуск сетевого компонента. Оставьте окно открытым и запустите Discord.
4. Если Discord продолжает загружаться, выключите обход, выберите A или B и включите его снова. Кнопка **«Проверить»** покажет доступность DNS, сайта, API и Gateway. Голос можно проверить звонком.

## Обновления

При запуске OkkWay проверяет новые выпуски. Если версия доступна, в шапке появится кнопка обновления. Нажмите её для загрузки и перезапуска. Если обход включён, приложение предложит выключить его перед перезапуском. Проверку можно запустить и вручную. Ссылка на скачивание выше всегда ведёт к последнему стабильному установщику.

## Что изменилось в v1.8

- ds_helper получил новое имя OkkWay и значок «Фальц».
- В боковой панели появился раздел Discord. В нём собраны профили, кнопка подключения и диагностика. При смене профиля перемещается маркер выбора.
- У выполняющейся проверки появился анимированный индикатор. При отмене видны уже полученные результаты.
- Выпуски и автоматическая проверка обновлений доступны публично. Версия 1.7 может обновиться до OkkWay в существующей установке. Локальная история проверок сохраняется.

Браузер, настольный Discord и голос проверены с профилем C на одном домашнем подключении. Результат у другого провайдера может отличаться. Приложение использует zapret/winws и WinDivert. Лицензии, сведения об авторах и исходные архивы сторонних сетевых компонентов входят в установку.
